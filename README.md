# 16 Track Mixer Recorder

A Maker Hip app: a 16-track recorder and mixer for an Android phone or tablet.

0.1: record up to 16 tracks one at a time over each other (with a click and a one-bar count-in), mix them (fader,
pan, mute, solo, meters), see them as waveforms over time, import WAV files, and export the mix and the stems as WAV
(Music/MakerHip/16 Track/). Inputs: the built-in mic or a USB audio interface (Settings).

Built by GitHub Actions on every push: the APK is on the Releases page.
